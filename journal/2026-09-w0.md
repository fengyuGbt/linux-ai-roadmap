## Learned
- `ls -lh`: long format + human-readable sizes; the first column shows permissions (`drwxr-xr-x` = directory, `-rwxr-xr-x` = file)
- `mkdir` creates directories; `cd` moves into them; `cd ..` goes back; `rm -r` removes a directory and its contents
- `command -v` / `which` checks whether a tool is installed
- `htop` is the interactive process monitor (already installed via apt)
