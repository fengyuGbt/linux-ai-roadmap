# Resources

Curated, mostly free. Start with the starred (★) items — they cover 90% of Phase 1–3.

---

## Books (free or near-free)

| Resource | Why | Phase |
|---|---|---|
| ★ [The Linux Command Line](https://linuxcommand.org/tlcl.php) (William Shotts, free PDF) | The single best free Linux book; practical, English-first | 1–2 |
| [How Linux Works, 3rd ed.](https://nostarch.com/howlinuxworks3) (Brian Ward) | How the system actually fits together | 2–5 |
| [UNIX and Linux System Administration Handbook](https://www.admin.com/) | The sysadmin bible when you go deeper | 5 |
| [TLDP (The Linux Documentation Project)](https://tldp.org/) | Classic free guides & howtos | 1–3 |

## English-learning tips for tech

- Read **official docs in English first** — translations are usually a step behind.
- Keep a small "terms I looked up" list in your journal (English → 中文 gloss).
- Write journals in English; correctness matters less than consistency.
- When stuck, read `man` pages aloud-ish in your head — it builds technical vocabulary fast.
